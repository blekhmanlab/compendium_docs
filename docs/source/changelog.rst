# Human Microbiome Compendium
## Changelog

*1 April 2025*

## 1.1.1, April 2025

This patch adds a single file for users, `classifications.tsv`, that indicates the inferred taxon for each ASV described in the project ASV tables. `manifest.csv` was also added—this is a reference file used by the [microbiomap](https://blekhmanlab.github.io/MicroBioMap/) R package to retrieve specific versions of the data.

## 1.1.0, September 2024

This update introduces changes to multiple facets of the compendium. See the README.md for a detailed description of individual files.

#### Administrative
* `README.md` has been expanded to describe the data and its provenance.
* `CHANGELOG.md` has been added to provide a versioned record of changes here.

#### Classification
* **`taxonomic_table.csv.gz` is now built from taxonomic assignments made using the _SILVA v138.2 reference_.**

   * A version of this reference, formatted for use with DADA2, is included here as `silva_nr99_v138.2_train_set.fa.gz`. It was created using [code developed by DADA2 maintainers](https://github.com/mikemc/dada2-reference-databases/tree/main/silva-138.1/v1), but this is not associated with DADA2 and is provided here for convenience.
   * `taxon_corrections.tsv` was removed. The taxonomic classifications listed in this version now reflect the assignments made using the SILVA reference without any manual corrections.

      * Similarly, `missing_levels.csv` was added. Like the former taxon corrections file, this was generated using code developed for previous releases to identify taxon names that do not have the expected number of levels. In previous releases, these were corrected manually.

* **The [Greengenes2](https://doi.org/10.1038/s41587-023-01845-1) reference** has been used to generate a second set of taxonomic classifications, formatted for use with [QIIME 2](https://qiime2.org/).
* **ASV-level read counts** (and exact sequences) are now available for all samples.

#### Metadata
* `projects.csv` includes new project-level metadata, including new links between datasets and their publications.

   * The `asv_inference.tsv` file was consolidated into this new file.

* Sample-level attributes from BioSample have been added for all samples included in the compendium, in `tags.tsv.gz`.

## 1.0.1, January 2024

This release uses taxonomic classifications based on the **SILVA 138.0 Ref NR 99 reference**. The nomenclature used in this taxonomic table diverges from the output generated by DADA2 and the SILVA database. The "asv_assignments" table was corrected to fix entries in which the taxonomic levels were incorrectly inferred from the reference database by DADA2 (e.g. genus _Brassicibacter_ was listed as a family, genus _Gelria_ was listed as an order). The problem is documented in issues attached to repositories for [DADA2](https://github.com/benjjneb/dada2/issues/1293), [DADA2 reference databases](https://github.com/mikemc/dada2-reference-databases/issues/1), and our [MicroBioMap](https://github.com/seandavi/MicroBioMap/issues/13) library. In short, problems were noted in v138 of the SILVA database in which taxonomic names were not recorded properly if they were missing levels (e.g. a taxon has been assigned a proposed genus, but not a family). This was addressed in subsequent releases. However, [several dozen entries](https://github.com/mikemc/dada2-reference-databases/blob/main/silva-138.1/v1/bad-taxa.csv) remain incorrectly annotated in v138.1. Our 1.0.1 release corrects these by filling in the nomenclature gaps with "(unclassified)" and moving the existing data to the correct level. 2881 ASV assignments were affected out of about 4.3 million.
The new file "taxa_corrections.tsv" is a copy of the ["bad-taxa.csv"](https://github.com/mikemc/dada2-reference-databases/blob/main/silva-138.1/v1/bad-taxa.csv) list generated by Michael McLaren, with notes added to reflect what we changed.

_[Please note, our release notes previously stated the classifications reported in this release used SILVA v138.1; it was the **SILVA v138.0** reference that was used here. Consequently, some "problem taxa" corrected in v138.1 are not corrected here.]_
